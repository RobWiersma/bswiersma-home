# bswiersma.com

A compact static homepage for independent software projects. GridSafety and SpotifyBlazor are presented as selected projects; GitDrone / LovelyOSD is listed separately as an experimental personal project.

## Deploy
Upload `index.html`, `styles.css`, and the `assets` folder to the root of the `bswiersma-home` GitHub repository. The project logos currently load directly from the public GitHub repositories.

The site is static HTML/CSS and can be hosted on Azure Static Web Apps or GitHub Pages. No build step is required.
